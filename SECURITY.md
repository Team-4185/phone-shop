# Security Policy

## Supported Branches

Security fixes are handled on active development branches.

| Branch | Supported |
| --- | --- |
| `main` | Yes |
| `develop` | Yes |

## Reporting a Vulnerability

Do not open a public issue for a security vulnerability.

Report security concerns privately to the repository maintainers through GitHub.

Include:

- Vulnerability summary
- Affected endpoint, feature or component
- Steps to reproduce
- Potential impact
- Suggested fix, if available

## Security Scope

Relevant areas include:

- Authentication
- Authorization
- JWT handling
- Password reset flow
- Admin endpoint access
- User data exposure
- File and image upload
- CORS configuration
- Dependency vulnerabilities
- Sensitive configuration handling

## Response

Maintainers will review the report, confirm impact and prioritize a fix based on severity.
